# 数据真实性与边界

## 详情新增说明

处理器能力区间来自公开规格的定性解读，不是官方评级或跑分；逻辑 CPU / vCPU
与整颗宿主处理器规格分开显示。仅识别架构时不猜 SKU，未核实的 OEM 型号不归类。
来源目录见 [CPU-GUIDE.md](CPU-GUIDE.md)。

详情按概览 / 资源历史 / 线路观测 / 检测依据分区，固定标题与关闭按钮。
历史分区首次打开才加载，离开即取消请求和停止定时刷新，返回保留所选范围及显隐线路。
“查看全部线路”直接进入线路观测。分区本身不改变任何检测任务或周期。

详情线路可独立切换近 1 / 6 / 12 / 24 小时多序列折线图，仍使用官方 `public:getPingRecords`，
向接口传入所选小时数，并按同一范围过滤 / 统计；首页卡片仍固定近一小时。
预设区间每 60 秒刷新，关闭详情、切换分区或切换范围取消旧请求，迟到结果不覆盖新范围。
切换期间不把旧范围样本冒充新范围；同范围刷新失败可保留上次样本并提示。
长范围横轴同时标注日期，实际历史长度取决于面板保留设置，不补造未保存的样本。
协议 / 地址族分别绘制，reference 样本排除。负值为失败，0 ms
是有效样本；失败绘制 × 并断线，超出采样间隔 2.5 倍的空缺断线，不平滑、不削峰。
采样间隔默认取任务周期（缺省 60 秒）；至少三个样本全部为整分钟对齐时，兼容旧接口
的分钟聚合，将小于一分钟的周期提升到 60 秒。不把任意稀疏记录的长间隔推断成正常周期。
长范围还兼容 UTC 对齐的 5 分钟 / 1 小时聚合网格：至少三个不同样本时刻全部对齐，
且至少两对相邻时刻恰好间隔一个桶才采用；任意稀疏 / 偏移时间戳不据此放宽断线。
这是旧接口未返回聚合分辨率时的保守展示适配，不是原始探测周期的证明。
自定义起止时间按浏览器本地时区解释，拒绝无效日期、倒序、未来和超出保留时长的区间。
官方旧接口仅支持整数小时：从当前回溯至开始时间（向上取整小时），前端再精确裁剪
所选起止。它不是服务端任意日期查询，不能找回被清理的记录；固定自定义区间仅手动刷新。
面板返回 `ping_record_preserve_time` 时限制相应预设和日期；未知时默认最多回溯 168 小时，
前端保护上限 8784 小时，不声明此范围必有数据。
图例可显隐、全选或全不选，悬停或键盘 / 触控时间轴可查看邻近真实样本及其实际时间。
逐线路显示实际返回首尾、成功 / 失败 / 返回数，以及成功记录的最小 / 最大 / 算术平均 / P95；
P95 使用返回成功值的线性分位数，不含负值失败，也不是原始探测分布的 P95。
首尾跨度不等于连续覆盖，最新样本值不等于当前状态，自定义历史样本不标为当前延迟。
接口记录可能由服务端聚合，样本统计只针对返回记录，不代表缺测期间的实际丢包率。
刷新失败保留上次图表并明确提示；会话失效清空本组件样本。首页卡片历史条不变。

## 基础数据

浏览器从同源 `/api/rpc2` 获取公开设置、节点、最新状态、延迟任务和一小时记录。
实时状态每 5 秒刷新；历史和扩展约每 60 秒刷新，仅为进入视区的卡片加载。
离开浏览器前台暂停轮询。节点资料 / 任务 / 设置通过刷新按钮重新读取。
状态时间超过 90 秒或异常超前不视作在线；错误时保留最后一份历史，不延长在线有效期。
总收发速率只合计有效在线样本，并提示有效节点数；没有样本不是零流量。

详情的 CPU / 内存 / 下载 / 上传图表按需查询 `public:queryMetrics`，最多每条 120 点，
使用均值；仅方法不存在时回退 `common:getRecords`。1 / 6 / 24 小时范围可选，
空值或时间断档不连线；图中“峰值”是返回的聚合点最大值，不是原始采样峰值。
关闭详情或切换时间后忽略旧请求，避免迟到结果覆盖新范围。

## 延迟和评分

近一小时以 30 个真实两分钟桶展示，空桶灰色；桶内有任意失败则红色，否则取最大延迟，
大于 250ms 黄色，其余绿色。失败比例是已收到样本中的失败数 / 样本数，不是对断档的猜测。
该比例也不是严格 SLA、持续时间占比或业务吞吐损失率。
首页每卡片只展示一条主线路，其他线路保留在详情折线图。按节点绑定 / 全局优先任务 /
任务类型与 ID 稳定选择，不按最低延迟、当前成功或可见卡片顺序选线；失败和无样本不换线。
单行仅减少展示数量，不按主线路收缩评分范围；失败总数仍统计所有非 reference 返回样本。
每条序列至少 30 个返回记录且最新记录在五分钟内才参与当前评分；不足时标“采集中”，
不填充样本，不给出评级。部分线路达标时，只对达标线路评分并明确其范围；未达标线路的
失败仍在主线路或详情展示。此阈值只是最低展示置信门槛，不是统计显著性证明。

协议与地址族分别成序列，参考目标不参加主目标评分。最近五分钟无主目标样本时显示待检测 /
样本过期并停止评分。各条序列的近期最新值不会用更早的成功值顶替失败。

- 稳定分 = 达标且新鲜的主目标序列已收样本的成功比例 × 100。
- 线路分 = `max(0, 100 - 达标且新鲜的各序列成功延迟中位数的中位数 / 5)`。
- 总分 = 稳定分 × 70% + 线路分 × 30%，四舍五入；≥90 为 A，≥75 为 B，否则 C。
- MAD 抖动 = 成功延迟到中位数的绝对偏差中位数。

这是 Mint 的透明观测指标，不是官方评分、IP 信誉、服务商质量认证或速度保证。
ICMP 的失败比例称丢包率，TCP 称连接失败率，HTTP 称请求失败率，未知协议称探测失败率。
它们都不是业务流量丢失比例，不能把 TCP 连接失败或内核 TCP 重传冒称 ICMP 丢包。
全失败时线路分和总分未知，而稳定分可以为 0；没有任何样本时全部未知。

## 月度支出

续费月费、一次性溢价合计、当前溢价月摊、含溢价月均估算分别显示。首页默认仅显示续费
月费，可在主题设置开启“月度支出包含溢价月摊”。不把一次性收购成本重复算成每月费用。
溢价 / 折价均为人民币已确认金额。默认固定模式按明确收购日期和月数摊销，期满停止；
未填条件不推算。SAO 导入保留原溢价及收购价，不重复计算剩余价值或将整笔收购价当溢价。
兼容模式 `amortization:"sao"` 按收购到当前到期日的跨度（有效且小于 100 年）分摊；
无有效到期日则取已持有时长，最少一个 30 天月。此模式随续费变化，过期后仍沿用原
SAO 月摊口径，不是现金账单或“剩余待摊金额”。固定模式不受续费影响，二者明确区分。
仅日期的收购时间默认 UTC；迁移时记录原时区偏移，支持北京时间，不按服务器时区猜测。

汇率由管理员维护，代码与常用符号对应；人民币固定为 1，浏览器不发起第三方汇率请求。
离线导入可从原 SAO 同源报价生成同日静态快照，并显示来源 / 日期；不在主题包里固化生产汇率。
月付 / 季付 / 年付按月数归一，自定义天数采用 30 天标准月。缺数据分别报告，价格 0
不代表免费；面板明确免费价格 -1 和一次性周期 -1 按零续费月费处理。
统计面板提供的全部可见节点，不受搜索、分组或仅在线筛选影响。隐藏 / 删除节点对应的
溢价不参与访客的可见节点合计，但配置本身仍属于公开主题设置。详见 [配置说明](INSTALL.md)。

## Nekomari 扩展

扩展从 `public:getNodeInsights` 读取版本化快照；方法不存在时自动降级，不在前端伪造数据。
流媒体 / AI 超过 12 小时、回程超过 30 小时标过期。每项检测保留 probe / region 依据和解释。

- Netflix / YouTube：显示 Agent 实际服务页面证据，但不保证付费账户播放或完整内容库。
- ChatGPT / Claude / Gemini：新版 Agent 请求合规 / 登录 / 应用页面；明确地区拒绝才显示受限，
  识别到服务页面仅显示“页面可达”，不代表账号可登录或可对话。只有出口地区的旧结果仍中性显示
  “地区判断”，未接入的旧 Agent 不补造 Gemini 结果。风控、同意页面或不明响应均未知。
- IP：没有独立信誉数据库，明确不评分。网络类型 / 组织摘要来自现有 IP 信息提供方；
  无证据不标“住宅”。该摘要查询节点存储地址，不一定是代理 / NAT 后的真实出口。
- 回程：按明确选择的公共目标进行 ASN 观察，不证明双向对称、CN2 GIA 或业务 SLA。
  每 24 小时一次，与流媒体 6 小时周期独立，重启沿用持久化计划与原检测时间。
  未启用、失败、未到达、未识别、过期分别表示不同状态；详情 / 悬浮说明保留依据。
- 重传：Linux 主机区间 TCP RetransSegs / OutSegs，不是三网任务的丢包率；非 Linux、
  首次、无发包或计数重置均未知。
- 本期：只读有效 `traffic_up` / `traffic_down`，按节点 up/down/sum/min/max 口径显示；
  不回退到开机累计值。不支持这些字段的服务端显示未上报。

### 网络类型显示优先级

1. 节点标签中明确的类别（如 `家宽`、`教育网`、`数据中心`、`移动网络`）优先，
   标注“手动”，表示管理员意图，不是第三方认证。匹配完整标签，可带原有颜色语法，
   不要求是第一个标签。手动与自动结果不一致时，详情分别展示，不丢弃自动信息。
2. 没有明确类别时，使用未过期的有效自动类型摘要。
3. 旧摘要中的 `网络类型未知`、空值、接口缺失或过期都显示中性的 `未分类`，
   不再用第一条任意标签或 KVM / LXC 充当网络类型。

Nekomari v1.6.14 的自动摘要只从 ip-api.com 的 `hosting=true` 识别机房、
`mobile=true` 识别移动网络。两者均为 false，以及分类源不可用，都可能变为同一个
`网络类型未知`，仅凭该摘要无法区分这两种原因。组织名称来自另一数据源 ipwho.is，
组织可显示而类型未分类并不矛盾。`hosting=false` 不是“住宅”或“教育网”的证明。

类型不从节点名称、ISP / ASN 名称、CN2 / 9929 回程、IPv6、带宽或虚拟化类型推断。
详情“网络类型依据”提供手动标签、自动结果、组织来源与限制；旧后端无需升级即可使用。

## 隐私和预览

主题无第三方分析脚本、无外部字体请求，不接收 token。用户名密码只提交到同源登录接口。
Nekomari 扩展接口服从私有站点和隐藏节点权限，不返回原始出口 IP 或逐跳路由。
启用网络摘要会由服务端将已存节点地址发给配置的 IP 提供方，可在主题设置禁用扩展。
公开站点本来允许访问的数据仍然公开，请通过面板的私有站点 / 隐藏节点设置控制访问。
费用默认隐藏，可由顶栏切换；这是本机截图隐私开关，不会从 API 删除价格，也不是访问控制。
费用开关及卡片 / 列表偏好保存在当前浏览器。标签仅解析文字与允许列表内颜色，不执行 HTML。
外观偏好同样仅保存在本机；默认用 `prefers-color-scheme` 跟随系统并监听变化，
显式浅色 / 深色覆盖系统，选择“跟随系统”可恢复。旧版 `mint-dark=false` 因可能只是
默认自动写入，不再锁定浅色；旧版 `true` 保留深色。无需新增接口或写入后台设置。

`preview.png` / 移动端 / 深色图使用测试夹具并带有演示标识，不是实际商业节点或线路证明。
正式构建不包含这些夹具，不会在空站点注入演示节点。

## Passkey

兼容已安装 komari-passkey 插件的登录挂载点与按钮样式，不内置凭据、签名或登录绕过。
私有站点需要 Nekomari v1.6.14 的精确认证入口豁免；凭据管理和注册仍要求登录。
不修改用户原有 Passkey 插件、RP ID、允许来源或凭据。

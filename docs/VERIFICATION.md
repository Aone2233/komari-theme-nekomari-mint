## 自动化

- 主题：12 项单元测试，10 项 Playwright 浏览器测试（含私有站点、会话失效、空站点、
  搜索 / 筛选 / 详情、官方降级，以及 320 / 390 / 768 / 1440px 无横向溢出）。
- 主题：TypeScript / Vite 构建、ZIP 结构 / 清单版本 / 测试夹具排除、重复打包哈希一致，
  `npm audit --omit=dev` 无已知运行时依赖漏洞。
- 商店：直接调用官方 `theme_submission.py` 校验主题 ZIP 和预览图。描述使用商店当前
  接受的字符串格式，而非主题文档允许但提交脚本尚未接受的多语言对象。
- Nekomari：服务端 Go 全套测试通过，排除仓库既有的三项外部 IP 服务测试
  `TestIpInfo` / `TestIpApi` / `TestGeojs`；Agent 测试通过，排除外部连通性测试
  `TestICMPPing` / `TestTCPPing` / `TestHTTPPing`。
- Nekomari：服务端 / Agent `go vet`，扩展相关 race 测试，Agent Windows 交叉编译通过；
  使用 Go 1.27.2 构建的 Linux 开发二进制经 govulncheck v1.8.0 扫描未发现可达漏洞。
- 原面板前端：140 项测试（含五语言键一致性）、`audit:compiler`、`lint` 通过。
  本次未修改面板前端或其翻译，因此未重建 / 提交默认主题归档。

新后端代码推送后还需看 GitHub CI 的**同一 commit**结论。主题发布不等于后端发版；
未对生产节点执行升级，也未开启生产 SSRF 开关、修改其他团队的 topology 工作或提交
主题商店申请。

## 未验证或明确缺失

真实三网目标的全路径验证、Gemini 实测、IP 信誉数据源、其他 Komari 版本、反代子路径、
所有服务付费账号的实际播放 / 对话能力不在已验证范围。ASN 解析有单元测试，实际
`traceroute -A` 工具可用，但不能替代针对用户三网节点的低频授权探测。

测试截图和账号文件保存在仓库外，不进入主题包。仓库预览使用带有演示标识的测试夹具。

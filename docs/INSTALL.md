# 安装、配置与验证

## 导入和回退

在 Release 下载 `nekomari-mint.zip`，可先使用 `SHA256SUMS.txt` 校验，再从后台主题页
导入并启用。无需停机或修改原管理后台。保留原主题，回退时在同一页面切换即可。
不要将 GitHub Source code ZIP 作为主题包导入。

主题只负责展示现有面板数据，不会自动添加节点、购买探测服务、创建三网任务或更改告警。
请先确认 Agent 已接入面板，并为需要监测的节点分配延迟任务。

## Mint 主题设置

| 项目                   | 用途                                                               |
| ---------------------- | ------------------------------------------------------------------ |
| 首页标题 / 说明 / 页脚 | 纯文本显示，不执行 HTML                                            |
| 显示 Nekomari 扩展检测 | 允许读取扩展快照和已存节点地址的网络摘要；官方 Komari 自动降级     |
| 卡片主线路优先任务     | 有序选择已分配的任务，每张卡片只显示其中一条；未选择时稳定自动选择 |
| 逐节点主线路 JSON      | 如 `{"节点UUID":3}`，节点覆盖优先于全局优先任务                    |
| 电信 / 联通 / 移动任务 | 从已有 Ping 任务中选择；显式选择优先于任务名称识别                 |
| 人民币汇率 JSON        | 例如 `{"USD":7.2,"EUR":7.8}`，支持常见币种符号；人民币固定为 1     |
| 汇率快照说明           | 静态汇率来源与日期，手动编辑汇率时自动改为手动更新时间             |
| 月度支出包含溢价月摊   | 默认关闭；开启后将当前有效的溢价 / 折价月摊加入首页月均估算        |
| 不参与费用统计的节点   | 多选节点；其续费月费和溢价均不计入，不改变监控或节点资料           |
| 节点溢价 JSON          | 按 UUID 保存人民币溢价、收购日期和摊销月数，也可在首页可视化编辑   |

这些主题设置是面板的**公开设置**，不得放密码、API key 或其他秘密。
没有配置任务 ID 时，主题按任务名的“电信 / 联通 / 移动”、Telecom / Unicom / Mobile
识别运营商；仅命名并不能保证目标属于该运营商，请核实实际目标。未配置或无记录显示灰色。
卡片只显示一条主线路：逐节点覆盖 → 全局优先任务中首个已分配任务 → 稳定自动选择。
自动选择依次优先非运营商非 ICMP、其他非 ICMP、ICMP，同级按任务 ID；不选最快或最近成功的线。
指定任务已删除 / 未分配时明确提示，任务失败或无样本时不换线。单任务多序列按 TCP / HTTP /
ICMP、IPv4 / IPv6 / 未知稳定选一条，不混合数据。点击“查看全部线路”打开完整详情折线。
各项线路 / 稳定评分不按主线路收缩范围，但每条非 reference 序列须至少 30 个返回记录且
最新记录在五分钟内才参与当前评级；未达标仍展示失败记录，不能将主线路理解为只对这一条打分。
详情保留协议和 IPv4 / IPv6 的区分。官方旧记录无地址族时显示未知。
详情分为概览 / 资源历史 / 线路观测 / 检测依据，顶部标题与关闭按钮固定。
“查看全部线路”直接进入线路观测，资源历史与线路观测按需加载，离开分区暂停请求。
详情“线路观测”可独立选择近 1 / 6 / 12 / 24 小时或自定义日期，与资源历史的选择互不影响。
每次切换重新请求真实历史，统计对应所选范围；保留不足时留空，不复制一小时数据铺满。
自定义日期使用浏览器本地时区，限制在面板保留时长内，不接受倒序或未来时间。
旧接口从当前回溯后精确裁剪自定义区间，不是任意日期服务端接口；该模式仅手动刷新。
图例支持全选 / 全不选，统计可展开查看各线路返回范围、样本数和最新 / 最小 / 最大 / 平均 / P95。
ICMP 丢包率、TCP 连接失败率与 HTTP 请求失败率分别显示，不将首尾跨度当作连续覆盖或 SLA。
详情桌面最大宽度为 1040px，手机端随视口收缩，长字段自动换行，不需要横向拖动。

### 网络类型与手动分类

网络类型不是运营商名称或回程线路。已确认节点用途时，可以在面板的节点标签里添加
完整类别，如 `家宽`、`教育网`、`数据中心`、`移动网络`（支持 `家宽<Green>`）。
主题优先显示明确类别并标“手动”；不修改原标签，也不会把它当作第三方住宅认证。
没有手动类别且自动摘要无法确认时显示 `未分类`，详情可展开“网络类型依据”。

`IPv6`、`9929`、`CN2 GIA`、`独服`、`软银线路`、带宽和 KVM / LXC 都不等于住宅或机房属性。
不要为了消除“未分类”给所有 VPS 强行标家宽；第三方 `hosting=false` 也不能证明住宅。

### 费用与溢价

先使用顶栏“显示费用”，再点击“月度支出”右上角“明细”。管理员登录后可点击
“编辑费用设置”，逐节点填写溢价 / 折价金额、收购日期、摊销月数和排除项，或修改汇率。
点击“保存费用设置”会保存到原面板的主题设置 API，官方 Komari 同样可用，无需升级后端。
访客只能查看，服务端仍要求管理员权限；隐藏金额时不开放金额编辑。

溢价是**额外支付金额**，不是完整收购价。例如续费为 120 元 / 年，额外溢价 120 元，
选择摊销 12 个月：续费月费 10 元，当前溢价月摊 10 元，含溢价月均估算 20 元。
负数表示折价。当前版本不根据剩余价值自动推算收购溢价，请手动填写已确认金额。

后台“节点溢价 JSON”也可直接填写：

```json
{
  "替换为节点UUID": { "amount": 120, "acquiredAt": "2026-10-01", "months": 12 }
}
```

默认固定模式每月摊销按 30 天，从收购日期 UTC 零时开始；期满停止。缺日期或月数时只记录一次性
总额，不参与月摊。不自动使用到期日或随着续费延长周期，避免续费让旧溢价再次摊销。
即使节点价格 / 汇率缺失，已填人民币溢价仍可独立计入；排除节点的溢价也一并排除。

### 复用原 SAO 配置

节点价格、币种、计费周期本就保存在面板的公共节点资料中，不需要复制或改价。
独立的 SAO 主题设置不会被 Mint 自动读取；离线迁移工具可从管理员授权导出的数据准备方案：

```bash
node --import tsx scripts/import-sao.ts /private/import-input.json /private/import-plan.json
```

输入字段为 `sao` / `mint` 设置对象、`nodes` / `tasks` 数组、`rates` 汇率行数组
（`base` / `quote` / `rate` / `date`）、`rateSource` 来源及 `acquisitionOffsetMinutes`
日期时区偏移分钟。输出是待审核方案，不调用服务端、不保存登录凭据。
导出 / 方案含公开主题配置和账单，请放在仓库外的私有目录；写入前备份，并复核源数据未变化。

迁移保留 `amount` 原溢价与 `paidCny` 原收购价，二者分开，不从收购价再算一遍溢价。
`amortization:"sao"` 记录按收购日到当前有效到期日的跨度分摊，无有效到期日时按持有时长，
最少一个 30 天月；续费改变到期日也会改变月摊。与原 SAO 相同，此值是成本口径估算，
不是本月现金支出，过期后不会自动变成零。需要期满停止时改用固定月数模式。
仅有日期的旧记录需明确原日期时区；北京时间为 `acquiredOffsetMinutes:480`。

原 `homepagePingBindings` 按 UUID 转为 Mint 逐节点主线路，多个绑定时采用最小任务 ID；
已删除或未分配的任务会列出警告，不猜替代线路。原排除项必须唯一匹配节点。
已有 Mint 溢价冲突会拒绝生成，已有 Mint 主线路、非人民币汇率和统计开关优先保留。
初次迁移且没有统计开关时开启“包含溢价月摊”，便于复用 SAO 的含溢价月均展示。
需要补汇率时只接受与 CNY 同日的 USD 基准报价，转为人民币静态快照并记录来源 / 日期；
之后不自动联网刷新，也不因汇率变化重算已经保存的溢价。

续费月费先折算人民币，再按周期归一：30 天为月付、92 天为季付、180 / 182 天为半年、
365 天为年付（除以 12）、730 天为两年（除以 24），其他自定义周期按天数 / 30 计算。
一次性计费 `-1` 不贡献续费月费；价格 `-1` 为明确免费，`0` 或空价格仍视为未填写。
空币种、缺汇率或无效周期单独提示，不假定美元或人民币，不猜测实时外汇。
年付折算与旧版统一乘 30 / 365 略有差异，这是校正月均口径，不是改动原节点价格。

保存前会重新读取设置，合并其他字段；检测到别处修改了费用配置时要求重新打开窗口，
避免覆盖旧草稿。原生 API 没有原子版本锁，仍不建议多处同时保存。已有节点价格、账单、
三网任务选择和其他主题设置均不主动改写。所有费用配置是公开主题数据，并非私密账本。

## 扩展端

请参阅 [Nekomari Mint extension](https://github.com/Aone2233/Nekomari/blob/main/docs/MINT-THEME.md)。
完整功能需要对应的服务端 / Agent；ZIP 导入不会升级后端。
回程需要额外安装支持 ASN 的完整 `traceroute`，并明确配置实际三网公共探测目标；默认关闭。
只配置有权探测的目标。回程目标会在公开摘要中出现，不应填写敏感地址。

## 真实实例浏览器自检

脚本不创建账号、节点或任务，也不更改主题。先完成导入及真实 Agent 接入，再运行：

```bash
node scripts/smoke.mjs http://127.0.0.1:25775
```

可选 `MINT_SMOKE_CREDENTIALS` 指向只含 `username` / `password` 的私有 JSON 文件，
用于验证后台与主题设置。不要将它提交到仓库。私有站点需要此文件。
`MINT_SMOKE_TASK` 可要求页面包含指定真实任务名；`MINT_SMOKE_OUTPUT` 指定截图目录
（默认 `test-results/real-smoke`）。输出不包含凭据，截图仍可能含节点信息，请自行保护。

Nekomari 实例还可设置 `MINT_SMOKE_PANEL_ROUTES=1`，验证 `/admin`、`/install`、
`/terminal` 仍由面板提供，正常运行时 `/database-recovery` 保留面板的重定向，
`/plugin/*` 仍交给主题。官方 Komari 1.6.0 的路径保留策略不同，不启用此专项断言。

## 排错

- 空白或连接异常：检查面板 `/api/rpc2` 是否同源可访问；子路径部署未验证。
- CPU / 内存为横杠：确认 Agent 在线且采样质量有效，90 秒未上报会判为离线。
- 三网没有曲线：检查任务已分配给该节点、名称 / 主题映射正确，并等待实际采样。
- 有网速但本期未上报：只有系统累计网卡计数不足以代表本期账单流量，需可信流量周期数据。
- AI 显示地区判断：这是刻意区分检测依据，不代表主题故障。
- 回程未知：检查 Agent 版本、目标配置、traceroute 的 ASN 支持及节点网络权限。
